# Archiwum — dokumenty planistyczne z marca 2026

**Te cztery pliki opisują projekt sprzed implementacji i NIE opisują stanu systemu.** Powstały w marcu 2026 jako drafty produktowo-techniczne, zanim powstał kod. Zawierają zdania w rodzaju „0% logiki biznesowej", listy modułów do zbudowania i szacunki, które rozminęły się z rzeczywistością o kilka miesięcy.

Zostają w repo, bo dobrze tłumaczą **dlaczego** produkt wygląda tak, jak wygląda: kryteria doboru MVP, filozofia etapowania koncentrycznego, segmentacja rynku. To wciąż użyteczny kontekst produktowy — pod warunkiem, że nikt nie czyta ich jak opisu działającego systemu.
